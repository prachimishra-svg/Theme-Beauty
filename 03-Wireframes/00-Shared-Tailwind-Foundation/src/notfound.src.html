NUDGE Beauty Theme: 404 page not found wireframe · single responsive file

Phase 4, page 24 of 25. The native Shopify 404 page (404.json), built with Tailwind utilities and the shared components mapped to the Design Variables. The announcement bar, header and footer are the shared sections. All wording is sample content; collection links are sample menu items. Placeholders only: no illustration or photography. Use Width preview for 1920, 1440, 1280, 1024, 768, 430, 390 and 320 px.

Review notes: purpose, sections, decisions, Shopify (open)

Purpose

A visitor who followed a broken or old link should know in one second what happened and have an easy way to carry on: search, shop, or go home. Nothing else is on the page.

Sections, top to bottom

  • A large "404" in the display face, a short title and one sentence
  • A search form (native store search)
  • Two buttons: Continue shopping and Go to the homepage
  • A short row of popular links, taken from a menu

Decisions to confirm

  • The page keeps the shared header and footer, so navigation and the header search are still available.
  • No illustration, no joke copy and no product grid: the aim is to get the visitor moving, not to entertain. A featured collection can be added as an optional section later.
  • The popular links are a theme-editor menu (sample: Best sellers, Skin care, Makeup, Hair, Body); they are not generated from analytics.

Not drawn

  • Smart "did you mean" suggestions, live chat or redirect managers (each needs an app; broken URLs are redirected in Shopify admin under Navigation, URL redirects)

Shopify build

Template 404.json with a main-404 section. The search is a plain form to routes.search_url with name="q" and type="product,article,page"; the buttons use routes.all_products_collection_url and routes.root_url; the links are a link-list setting. The response status 404 is set by Shopify. No app is involved.

GlobalAnnouncement bar, header (sticky) and footer: the shared sections. Responsive: below 1024 px a one-row header with the menu in a left drawer; footer groups are tap-to-open rows below 768 px.
