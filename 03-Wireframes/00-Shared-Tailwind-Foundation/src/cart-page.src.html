NUDGE Beauty Theme: cart page wireframe · single responsive file

The full-page cart, built with Tailwind utilities and shared components mapped to the Design Variables. The announcement bar, header and footer are the shared sections. Products, prices and the free-shipping threshold are sample content standing in for the Shopify cart. Placeholders only: no photography. Use Width preview for 1920, 1440, 1280, 1024, 768, 430, 390 and 320 px.

Review notes: approved features, exclusions, decisions, Shopify (open)

Approved Beauty cart features (25 Yes in the revised workbook)

Source: Homepage_CRO_5_Theme_Final_Comparison_Revised_Final.xlsx, sheet Beauty - PLP, PDP & Cart (Cart: 25 kept, 2 not recommended), with Cart Additional CRO Recs and Removed - PLP, PDP, Cart. Full checklist: CART-FEATURE-ANALYSIS.md.

  • Full cart page
  • Title and item count
  • Free-shipping progress
  • Lines: image, title, variant, price, quantity
  • Live quantity stepper, remove, remove with undo
  • Compare-at price and line saving
  • Stock warnings on lines (real stock only)
  • Delivery estimate date
  • Native upsell (one or two low-priced items)
  • Order note and gift message
  • Subtotal, saving, taxes and shipping note
  • Checkout button with lock, express buttons
  • Trust line, policy links, support contact
  • Continue shopping as a quiet link
  • Sticky checkout bar (phones)
  • Empty state with collection links; mobile-first layout

Not drawn (No or Removed for Beauty)

  • Discount code box (Shopify takes codes at checkout)
  • Gift wrap product, free gift line
  • Frequently bought together as its own block (merged into the upsell)
  • Change size or option in the cart (No for Beauty)
  • Installment messaging (No)
  • Reserved-for-10-minutes timer (fake urgency)
  • Save for later, quantity discounts, shipping rate calculator, live chat

Shopify build

Template cart.json with a main-cart section over the native cart object and the Cart Ajax API (/cart/change.js); lines, summary and upsell are blocks and snippets; free-shipping threshold, upsell and express buttons are theme-editor settings. No app is involved. Tailwind utilities compile into one theme stylesheet from the same token-mapped config.

GlobalAnnouncement bar, header (sticky) and footer: the shared sections. The cart icon is the current page. Responsive: below 1024 px a one-row header with the menu in a left drawer; footer groups are tap-to-open rows below 768 px.
