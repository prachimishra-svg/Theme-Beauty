NUDGE Beauty Theme: Contact us wireframe · single responsive file

Phase 1, page 1 of 25. A native Shopify contact page (page.contact) built with Tailwind utilities and the shared components mapped to the Design Variables. The announcement bar, header and footer are the shared sections. Contact details, hours and reply time are sample content that the merchant sets in the theme editor. Placeholders only: no photography. Use Width preview for 1920, 1440, 1280, 1024, 768, 430, 390 and 320 px.

Review notes: purpose, sections, decisions, Shopify (open)

Purpose

Give a customer the quickest route to a person, and deflect common questions to self-service pages first (FAQ, shipping, returns) so the form is the last step, not the first.

Sections, top to bottom

  • Page title and short intro
  • Contact form (name, email, optional phone, topic, optional order number, message)
  • Contact details: email, phone, hours, address (each one hidden when empty)
  • Quick answers: links to FAQ, shipping and returns
  • Social links stay in the shared footer

Decisions to confirm

  • Reply time, phone, hours and address are bracketed placeholders; nothing is promised until the merchant fills them in.
  • Topic list is a theme-editor setting (sample: Order, Product advice, Returns, Something else).
  • No live chat, no booking or consultation widget, no map embed (each needs an app or an external service).

Not drawn

  • Live chat, WhatsApp widget, appointment booking, store-locator map (a separate page, only if the store has locations)
  • File upload (not supported by the native contact form)

Shopify build

Template page.contact.json with a main-page intro section and a contact-form section built on the native {% form 'contact' %}. Success uses form.posted_successfully? and errors use form.errors; extra fields post as contact[Topic] and contact[Order number]. Spam protection is Shopify's own. Details are blocks (email, phone, hours, address) and settings; quick-answer links are a menu or link-list setting. No app is involved.

GlobalAnnouncement bar, header (sticky) and footer: the shared sections. Responsive: below 1024 px a one-row header with the menu in a left drawer; footer groups are tap-to-open rows below 768 px.
