Product card and product images

Product images: packaging proportions and gallery thumbnails

Frames use the product-image tokens (--product-image-aspect-card, -aspect-thumb, -fit, -position, -thumb-size). The images are generated placeholders. Thumbnails are buttons, so each one is also a tap target.

Drawer width (specimen)

The panel uses --layout-drawer-width as its width. The frame stands in for the viewport and takes the tier that width belongs to: a full-width sheet below 600px, a 26rem panel from 600px. The Validation panel measures the same markup off-screen at 8 widths from 320 to 1440px.

11 · Validation

Live checks against the real CSS

Run in your browser against the loaded stylesheet. Known fail marks a combination the system documents as not allowed (for example muted text on Blush); it counts as expected.
